**Lantern Market** — an original spot-the-difference game. Two near-identical
pictures side by side, five lantern-lit scenes (market, river festival, tea
garden, night bazaar, harbor), 5–9 differences each, timer, streak scoring,
3 lives, best score saved. Click a difference, or move the cursor with the
arrow keys and press Enter. P pauses. All art is drawn procedurally on canvas
and all sounds are synthesized with WebAudio — no assets, no network.
